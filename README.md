# claude-config

Private Claude Code plugin marketplace.

## Installation

On any device with Claude Code:

```
/plugin marketplace add milwis/claude-config
/plugin install milwis-coding-toolkit@milwis-marketplace
```

## Updating

After pushing changes to this repo, on each device run:

```
/plugin marketplace update
```
