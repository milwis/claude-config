# claude-config

Private Claude Code plugin marketplace.

## Installation

On any device with Claude Code:

```
/plugin marketplace add milwis/claude-config
/plugin install milwis-coding-toolkit@milwis-marketplace
```

## Updating

After pushing changes to this repo, on each device run:

```
/plugin marketplace update
```

## Contents

- **milwis-coding-toolkit** — Language-specific coding agents, workflow skills (`/brainstorming`, `/writingplans`, `/executingplans`, `/new-project`, `/lang-guidelines`), and discipline skills (`verification-before-completion`, `test-driven-development`, `systematic-debugging`).
