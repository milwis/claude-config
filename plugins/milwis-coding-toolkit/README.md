# milwis-coding-toolkit

Language-specific coding expert agents that prevent common AI code generation errors.

## Agents

| Agent | Language | Focus |
|-------|----------|-------|
| python-pro | Python 3.13+/3.14 | AI error prevention, PEP 8, type hints, async, security |
| javascript-pro | JavaScript/TypeScript | AI error prevention, ES2025, Airbnb/Google style, OWASP |
| sql-pro | SQL | AI error prevention, query optimization, injection defense |
| php-pro | PHP 8.3+/8.4/8.5 | AI error prevention, PSR-12, Laravel/Symfony |
| backend-security-coder | Multi-language | Secure backend coding |
| code-reviewer | Multi-language | Code review |
| database-optimizer | SQL/NoSQL | Database performance |
| debugger | Multi-language | Bug investigation |
| mobile-pwa-developer | Web | PWA development |
| refactoring-specialist | Multi-language | Code refactoring |
| test-automator | Multi-language | Test automation |

## Skills

- `/lang-guidelines <language>` — Create or update a language-specific expert agent

## Updating agents

Run `/lang-guidelines <language>` to update an agent with the latest research, then copy the updated file here and push.
